# Credits

Every creature is made in code. Other assets are made in code too, or are listed here with their source
and licence (CC0 files, or OFL fonts).

| Asset | Source | Licence |
| --- | --- | --- |
| Creature geometry, facial pixels, egg, terrain, shaders and favicon | Generated by the source code in this repository | MIT |
| Creature voices | Web Audio oscillators generated from the genome | MIT |
| Interface and export typography | Browser/system fonts; no font files distributed or requested | System-provided |

No external model, sprite, image, audio or font files are used. Dependencies retain their own licences as recorded in package-lock.json.
